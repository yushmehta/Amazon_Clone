# Amazon_Clone
A fully responsive e-commerce web application inspired by Amazon, built using HTML, CSS, and JavaScript.
This project focuses on the frontend design and user interface, replicating key Amazon features such as product listings, navigation bar, product details page, and shopping cart layout.

🚀 Features

🧭 Responsive Navigation Bar with search box and category links

🛒 Product Listing Page displaying items dynamically

📄 Product Details Page with description, ratings, and price

💳 Cart Page UI for viewing selected items

🌙 Modern UI/UX with hover effects and smooth transitions

🛠 Tech Stack

HTML5 – structure and layout

CSS3 – styling, animations, and responsiveness

JavaScript (Vanilla) – interactivity and DOM manipulation
